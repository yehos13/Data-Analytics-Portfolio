# Musical Linguistic Corpus | Python · MySQL · NLP

## Description
Synthetic database with 30,000 song records and linguistic analysis using NLP tools.

## Tools
- Python
- Pandas
- MySQL
- spaCy
- NLTK
- ThreadPoolExecutor

## Key Features
- Synthetic database with 30,000 song records
- Verb tense detection across 7 grammatical categories
- Phrasal verb identification and classification
- Parallel processing with ThreadPoolExecutor
- Integration with WordNet and Argos Translate

## Results
- 30,000 songs generated
- 5.2M total words analyzed
- 4.7 phrasal verbs per song average
- Present simple: 42% · Past simple: 28% · Future simple: 12%
