# Student Database with Visual Analysis | Python · MySQL

## Description
Generation, storage and visual analysis of 1,000 student records using Python and MySQL.

## Tools
- Python
- Pandas
- Matplotlib
- Seaborn
- MySQL

## Key Features
- Generation and storage of 1,000 fictional records in MySQL
- Exploratory analysis with Pandas
- Grade distribution visualization by major and score range
- Scatter plots with color segmentation by performance range
