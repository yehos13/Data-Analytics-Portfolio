# Data Quality & Cleaning | SQL · MySQL

## Description
Detection and correction of inconsistencies in a relational sales database using MySQL.

## Tools
- SQL
- MySQL
- MySQL Workbench

## Key Features
- Null value detection and correction with UPDATE
- Duplicate record identification and elimination with DELETE
- Negative quantity and price detection
- Final data integrity report using UNION ALL
