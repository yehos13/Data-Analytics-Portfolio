# Data Analytics Portfolio
### Josue Carranza Saucedo

Data analysis projects using SQL, Power BI, Python (Pandas, NumPy, Matplotlib, Seaborn) and MySQL.

## Projects

### 1. Sales General Dashboard | Power BI
Interactive sales report with analysis by salesperson, region and period. Includes trend charts, geographic map and multidimensional visualizations.

### 2. Video Game Sales History | Power BI
Dashboard with main KPI, dynamic filters by year, region, genre, platform and publisher. Regional participation analysis and detailed records table.

### 3. Data Quality & Cleaning | SQL · MySQL
Detection and correction of inconsistencies in a relational sales database: null values, duplicates and negative quantities using UPDATE, DELETE and integrity report.
### 4. Student Database with Visual Analysis | Python · MySQL · Pandas · Matplotlib · Seaborn
Generation and storage of 1,000 student records in MySQL. Exploratory analysis with Pandas and grade distribution visualization by major and score range.

### 5. Musical Linguistic Corpus | Python · MySQL · NLP · spaCy · NLTK
Synthetic database with 30,000 song records. Linguistic analysis for verb tense detection and phrasal verbs using parallel processing with ThreadPoolExecutor.
## Tools & Technologies
SQL · MySQL · Power BI · Python · Pandas · NumPy · Matplotlib · Seaborn  NLP · spaCy · NLTK
